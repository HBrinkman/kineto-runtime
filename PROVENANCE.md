# Provenance

This repository is a runtime-only extraction from the private Kineto editor
repository. Its first content commit is a snapshot, not a history import: no
commit, branch or object from the private repository is included.

## Changes made after extraction

Behaviour of the runtime source is unchanged. Changes are to tests, metadata,
paths and generated output:

- `engine/kineto_engine/tests/stroke_trim.rs`: removed the test that read the
  excluded showcase fixture (and its now-unused imports).
- `engine/kineto_engine/tests/vello_scene.rs`: reads Inter from
  `tests/fixtures/fonts/` instead of the editor's `assets/fonts/`.
- `runtimes/android/sample/.../HostSmokeTest.kt`: the "running animation
  changes pixels" test uses the synthetic `animated_sample.kvk` instead of the
  excluded showcase. Not run here (needs an emulator).
- `runtimes/parity/runtime_fixtures.json` and its mirror: removed the
  brand-character entry.
- `runtimes/web/pkg/*` and `packages/kineto_runtime/web/pkg/*`: rebuilt with
  `scripts/build_runtime_web.sh` from the source commit (rustc 1.95.0,
  wasm-bindgen 0.2.122). The source's committed copy was older: it lacked the
  raw `kineto_override_scalar` and `kineto_retain` exports. The
  `KinetoWasmPlayer` API is identical.
- `engine/kineto_engine/Cargo.toml`: `license`, `repository` and
  `publish = false` metadata.
- `packages/kineto_runtime/ios/kineto_runtime.podspec`: homepage, author and
  licence metadata (was a private URL, a placeholder address and `UNLICENSED`).
- Links from READMEs and comments to the excluded internal docs now point at
  `docs/BUILDING.md` / `docs/PLATFORM_SUPPORT.md`.

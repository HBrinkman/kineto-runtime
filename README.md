# Kineto Runtime

Public distribution home for the **Kineto animation runtime** and its integration SDKs.

Kineto is an iPad-first animation editor. Runtime packages (`.kvk`) are intended for playing exported artwork and animations in a host application. This repository is separate from the private Kineto editor repository.

## Current status

**Repository setup only. No SDK source, installable package, binary release or supported-version tag has been published here yet.**

Do not use a Git URL from this repository as a Swift Package, Flutter dependency or production runtime until a release and tested installation instructions are available.

## Intended scope

The public distribution will contain only reviewed runtime material:

- Runtime engine and format/schema material required for playback, if approved for source distribution.
- Platform SDKs and integration instructions.
- Minimal distributable examples, compatibility information and release checksums.
- Applicable licenses and third-party notices.

The editor UI, authoring tools, purchase/paywall implementation, analytics configuration, signing credentials, private project history and internal research do not belong here.

Source versus binary distribution, licensing, initial platform support and release automation are still to be finalized. The repository being public does not itself grant an open-source license or imply every platform is production-supported.

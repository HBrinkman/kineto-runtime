## Prebuilt engine libraries

The published package contains libraries compiled from the Kineto Rust engine:

| File | Built with |
| --- | --- |
| `ios/kineto_runtime/KinetoRuntimeC.xcframework/*/*.a` | feature `metal-render` |
| `android/src/main/jniLibs/*/libkineto_engine.so` | feature `android-render` |
| `web/pkg/kineto_engine_bg.wasm` | feature `web-runtime` |

Each statically links third-party Rust crates. Every crate in the engine's
resolved dependency graph (all features, build-only and target-specific
dependencies included, conservatively) is listed with its version, SPDX
expression and repository in `licenses/rust-crates.tsv`; the license and
notice texts are in `licenses/RUST_LICENSE_TEXTS.txt`. All are available under
MIT, Apache-2.0, BSD, Zlib, ISC, CC0-1.0, Unicode-3.0 or Unlicense terms.
`cbindgen` (MPL-2.0) only generates the C header at build time and is not
linked; `r-efi` is used under MIT OR Apache-2.0.

Apps that ship this package redistribute these libraries and must carry those
notices.

`web/pkg/kineto_engine.js` and `.d.ts` are glue generated by wasm-bindgen
0.2.122 (MIT OR Apache-2.0); the generated glue carries no separate notice.
